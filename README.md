## What changed, and why

### Structure (recruiter / ATS best practice)
1. **Objective → Professional Summary.** Modern resumes open with a sharp 4–5 line summary aimed at the target job. The old generic "objective" statement is outdated and wastes the most valuable space on the page.
2. **Added a professional headline** ("Customer Service Professional") so recruiters and applicant-tracking systems (ATS) instantly know the target role.
3. **Added a Core Skills section** packed with customer-service keywords (complaint resolution, needs assessment, service recovery, CRM, etc.). This is what both human recruiters and ATS software search for.
4. **Reverse-chronological experience** (newest first) with consistent formatting: company — location — right-aligned dates, italic job title, then bullets.
5. **Education trimmed to tertiary degrees + certification.** Primary school and NECO are dropped — with a Master's degree, secondary-school entries only dilute the CV. (They remain in the original file.)
6. **Referees removed from the resume.** Global standard is "Available upon request" — full referee details (and their private phone numbers) should only be shared when asked. The original file still has the referee list when you need it.
7. **Hobbies removed.** "Making Friends" etc. does not help a customer service application and costs valuable space.

### Content (written for customer service)
8. **Duty lists rewritten as achievement-focused bullets** starting with strong action verbs, always reframed around the *customer*: first point of contact, enquiry resolution, follow-up, complaint handling, service recovery.
9. **The most customer-relevant experience is now impossible to miss** — the Guaranty Trust Bank customer-service attachment and the customer-facing sales and insurance roles now read as direct evidence for a service job.
10. **Fixed errors:** "NATION COUNCIL" → "National Council for Arts and Culture", "NYSC Corp" → "NYSC Corps", "MANAGING DIRESTOR" typo eliminated (referees section dropped), punctuation and tense standardised (consistent past tense).
11. **Cover letter added** — a tailored, one-page letter that tells the customer-service story and links her strongest service moments to what hiring managers want.

### Design
12. **Clean, single-column, ATS-safe layout** — no tables, text boxes, columns, or graphics that break applicant-tracking software. Standard section headings, standard bullets.
13. **A4, two pages, balanced** — navy accents, readable Calibri/Helvetica, dates aligned right, each job entry kept whole on one page (no orphaned bullets).
14. **Same design language** across resume and cover letter for a consistent application pack.

## Before you send it — required checklist

- [ ] **Replace `[Phone Number]` and `[Email Address]`** (and `[Date]` in the cover letter) with real details.
- [ ] **Add any work, freelance, volunteering, or training since 2017.** The last role on file is 2017 — anything more recent must be added to avoid an unexplained gap.
- [ ] **Add real numbers where you can** (e.g. "served 30+ customers daily", "handled 50+ calls per shift", "95% satisfaction"). Only use figures that are true — quantified bullets are the single biggest upgrade you can still make.
- [ ] **Tailor every application:** copy 3–5 keywords from the job advert (e.g. "call centre", "Zendesk", "retention") into the Core Skills and bullet points — this dramatically improves ATS ranking.
- [ ] If applying to US employers, "references available upon request" can be removed entirely (it is assumed). In Nigeria/UK it is fine as-is.
- [ ] Save the final version as PDF named like `Fatima_Ali_Customer_Service_Resume.pdf` — and only send the Word file if specifically asked.
